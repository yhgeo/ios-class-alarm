# 响课

按课表自动设置次日早晨的闹钟 —— 改一次课表，闹钟跟着变，不用每天手动设。

> **系统要求**：iPhone（arm64）/ iOS 16 及以上 / 已安装 [TrollStore](https://github.com/opa334/TrollStore)

## 为什么需要它

iOS 16 的快捷指令能「添加闹钟」却**不能删除闹钟**，纯快捷指令方案会让闹钟越积越多。

响课借助 TrollStore 的权限，**直接读写系统「时钟」App 的闹钟**，所以能增、能删、能改，
而且设出来的是**真·系统闹钟**（正常响铃、支持贪睡），不是容易被忽略的普通通知。

## 安装

1. 打开本仓库的 **Actions** 页面，点最近一次成功的 `Build XiangKe IPA`
2. 在页面底部 **Artifacts** 区域下载 `XiangKe-ipa`（下载下来是 zip，解压得到 `XiangKe.ipa`）
3. 用 TrollStore 打开 `XiangKe.ipa` 安装
4. 桌面出现「响课」图标

> 下载 Artifacts 需要登录 GitHub 账号。

## 快速上手

### 1. 录入课表

打开响课 → 点「编辑课表」：

页面顶部有两个**平级页面**，点一下切换：

**每周课表** —— 按星期排的常规课表

- 右上角 `+` 添加一节课：选星期、起止时间、填课程名
- 点某一行可修改，**左滑删除**

**自定义课表** —— 为某一天单独排课（临时调课、某天有加课）

- 右上角 `+` → 先填日期（`YYYY-MM-DD`）→ 再填这节课
- 某天的安排**优先于**每周课表，只影响那一天
- 把某天的课全删光 = 那天停课；再左滑那行「当天无课」就能恢复按星期上课

提前量不在这里，在主页「设置」里改（默认 30 分钟）。

### 2. 应用闹钟

回主页点「立即应用（设置次日闹钟）」。

它会算出**次日第一节课**的开始时间，减去提前量，写进系统闹钟。

举例：提前量 30 分钟，明天第一节课 8:00 → 闹钟设为 **7:30**。

### 3. 核对

打开系统「时钟」App，能看到一个标题形如 `课表|周二 高等数学` 的闹钟。

这个 `课表|` 前缀是响课的标记 —— 清理时**只删自己创建的**，不会动你手动设的闹钟。

### 4. 设置

主页「设置」里可以：

- 改**提前提醒**的分钟数
- **载入示例课表** —— 想先看看效果
- **存储自检** —— 看课表存在哪、是否可写、上次保存是否成功

## 课表 JSON 格式

如果课表经常变、想用电脑批量编辑，可以把课表写成 JSON 放到网上，让响课拉取。

### 完整示例

```json
{
  "version": 1,
  "advanceMinutes": 30,
  "courses": [
    { "weekday": 1, "start": "08:00", "end": "09:40", "name": "高等数学" },
    { "weekday": 1, "start": "10:00", "end": "11:40", "name": "大学英语" },
    { "weekday": 2, "start": "09:00", "end": "10:40", "name": "线性代数" },
    { "weekday": 3, "start": "08:00", "end": "09:40", "name": "数据结构" },
    { "weekday": 5, "start": "08:30", "end": "10:10", "name": "计算机网络" }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `version` | 数字 | 格式版本，固定填 `1` |
| `advanceMinutes` | 数字 | 提前量（分钟）。**闹钟 = 第一节课开始时间 − 该值** |
| `courses` | 数组 | 常规周课表，每个元素是一节课 |
| `courses[].weekday` | 数字 | 星期几：`1`=周一，`2`=周二 … `7`=周日 |
| `courses[].start` | 字符串 | 开始时间，`"HH:mm"`，24 小时制 |
| `courses[].end` | 字符串 | 结束时间，`"HH:mm"`。**只影响界面显示，不影响闹钟** |
| `courses[].name` | 字符串 | 课程名，会出现在闹钟标题里 |

> **响课只关心每天最早的那节课** —— 闹钟时间由它决定，同一天的其他课只用于展示。

### 按日期写课表（`overrides`）

大学课表每天都不一样，用 `courses` 按星期写反而别扭。
这时可以**只用 `overrides`**，一天一天精确写：

```json
{
  "version": 1,
  "advanceMinutes": 30,
  "courses": [],
  "overrides": {
    "2026-10-13": [ { "start": "08:20", "end": "10:00", "name": "模拟电子技术基础" } ],
    "2026-10-14": [ { "start": "18:30", "end": "20:10", "name": "大学物理实验（2）I" } ],
    "2026-10-15": []
  }
}
```

| 规则 | 说明 |
|---|---|
| 键 | 日期，格式 `"YYYY-MM-DD"` |
| 值 | 当天的课程数组；**空数组表示当天没课**（放假） |
| 没列出的日期 | 回落到 `courses` 的常规课表；`courses` 也是空的话，就当没课 |

`courses` 和 `overrides` 可以混用，**`overrides` 里的日期优先**。

> 当前版本没有编辑 `overrides` 的界面，只能通过导入 JSON 来设置。

### 怎么放到网上

推荐用 GitHub Gist（免费、随时改、有版本记录）：

1. 打开 https://gist.github.com
2. 「Filename」填 `timetable.json`，内容粘贴上面的 JSON
3. 点 **Create public gist**
4. 复制浏览器地址栏里的地址就行（形如 `https://gist.github.com/你的用户名/xxxx`）
   —— 响课会**自动补上 `/raw`**，不用自己找 Raw 按钮

然后：响课主页 →「导入课表（URL）」→ 填地址 → 导入。

导入页有两种填法：

- **填 https 地址** —— 在输入框里输入，或长按输入框选「粘贴」
- **点「从「文件」选 JSON」** —— 把课表文件放进「文件」App 直接选，**不需要网络**

导入页会记住上次用过的地址，下次打开已经填好了。

> 💡 想把电脑上的课表 JSON 传到手机：用**微信/QQ 的文件传输助手**发给自己
> （Windows 没有 AirDrop），手机上点开文件 → 存到「文件」App，
> 再在导入页点「从「文件」选 JSON」选它。

> ℹ️ 巨魔（TrollStore）环境下系统禁止 App 主动读剪贴板，所以没有「一键粘贴」按钮。
> 在输入框里长按选「粘贴」仍然可用。

> ⚠️ 必须是 **https** 开头的地址。iOS 默认禁止明文 http 请求，填 http 会被拒绝。
>
> 如果填的是 GitHub 仓库里的文件地址（`github.com/.../blob/...`），响课会自动转成 raw 地址。
> 万一下载到的是网页而不是 JSON，日志区会明确提示你改用 raw 地址。

导入会**整体替换**当前课表并立即保存。导入完回主页点「立即应用」即可生效。

## 自动运行（不用每天手动点）

三条路。**推荐方案一** —— 它是目前唯一「锁屏时也能跑」的。

> 为什么这么绕：iOS 锁屏时**禁止打开 App / 打开 URL**（方案二因此失效），
> 而「后台刷新」（方案三）由系统择机，实测三天一次都没跑。
> 方案一绕开了这两个限制 —— 它不打开任何 App，只是**开关时钟里已有的闹钟**。

### 方案一：快捷指令开关闹钟（推荐，锁屏可用）

思路：你的课表里**上午的最早课只有 2 种时间**（08:20 / 10:15），
所以不需要「每天算一个新的闹钟」，只要：

- **准备**（一次）：在时钟里建好这 2 个时间各减 30 分钟的闹钟；
- **每天**（自动）：快捷指令查出明天该用哪个，**打开它、关掉另一个**。

「开关闹钟」这个动作不需要打开 App，所以锁屏时也能执行。
**10:30 及以后开始的课不设闹钟。**

> 📱 手机上照着做的图文版：**https://yhgeo.github.io/ios-class-alarm/**

#### 第 1 步：在时钟里建 2 个闹钟

「时钟」→ 闹钟 → `+`，建 2 个。**时间必须准**，标签建议照抄：

| 标签 | 时间 | 对应你课表的 |
|---|---|---|
| 课表 07:50 | 07:50 | 最早课 08:20 |
| 课表 09:45 | 09:45 | 最早课 10:15 |

> 「重复」全部设成**不重复**。改提前量或改课表后，这两个时间要跟着改。

#### 第 2 步：搭快捷指令（9 个动作）

「快捷指令」→ 新建，**按下面的顺序**依次添加。

> 💡 「搜」那一列是**在动作搜索框里输入的关键词**。
> 注意 Apple 的中文用的是**「词典」不是「字典」**，搜「字典」是找不到的。
>
> 💡 顺序是特意排的：**先算日期 → 再取网络数据 → 再查表**。
> 这样第 4 步的输入会自动接上第 3 步，第 5 步的输入会自动接上第 4 步 ——
> **只有第 5 步的「键」需要你手动选一次变量**（见下方图示说明）。

| # | 动作（搜） | 设置 |
|---|---|---|
| 1 | **调整日期**（搜 `日期`） | 日期 = 当前日期（默认，不用改）；操作 = 添加；1 天 |
| 2 | **格式化日期**（搜 `日期`） | 日期 = 上一步结果；格式选「自定义」，填 `yyyy-MM-dd` |
| 3 | **获取 URL 内容**（搜 `URL`） | 地址填 `https://gist.githubusercontent.com/yhgeo/a1319b6b00cf0cd73c19a4b7f0d47fb8/raw/alarms.json` |
| 4 | **从输入获取词典**（搜 `词典`） | 输入 = 上一步的结果（默认就是） |
| 5 | **获取词典值**（搜 `词典`） | 输入 = 上一步的词典（默认就是）；<br>**「键」= 魔法变量「第 2 步的输出」** ← 唯一要手选的地方 |
| 6 | **开关闹钟**（搜 `闹钟`） | 闹钟选「课表 07:50」，操作 = **关闭** |
| 7 | **开关闹钟**（搜 `闹钟`） | 闹钟选「课表 09:45」，操作 = **关闭** |
| 8 | **如果**（搜 `如果`） | 第 5 步结果 **是** `07:50` → 里面放「开关闹钟」选「课表 07:50」，操作 **打开** |
| 9 | **如果**（搜 `如果`） | 第 5 步结果 **是** `09:45` → 里面放「开关闹钟」选「课表 09:45」，操作 **打开** |

##### 第 5 步的「键」怎么填（这一步最容易卡）

「获取词典值」有三个部分：

```
获取词典值
  从 [ 词典 ]        ← 输入，默认就是第 4 步的结果，不用动
  获取 [ 值 ]        ← 保持「值」
  键   [ ______ ]    ← 这里要填第 2 步的输出
```

**「键」不能用键盘打字**（每天日期都不同，必须动态取）。操作：

1. 点一下「键」右边那个输入框，弹出键盘；
2. **键盘上方那一排按钮里，找「魔法变量」**（图标像个小方块/闪电，通常在最右侧）；
3. 点开后选 **「格式化后的日期」**（就是第 2 步那个动作的输出）；
4. 「键」里会变成一个**蓝色小胶囊**，显示「格式化后的日期」——这就对了。

> 同样的手法后面还会用到：第 8、9 步的「如果」默认就接第 5 步的输出，
> 一般不用改；如果它显示的不是「词典值」，用同样的方式把它改成第 5 步的输出。

> 第 1、2 步的「日期」是**动作内部的字段**，不是另加一个动作 ——
> 「调整日期」放在第一个，它的日期字段默认就是「当前日期」。

> 两个「如果」**互相独立，不要嵌套**。先无条件关掉两个，再按匹配结果打开对应的那个 ——
> 这样不会出现「两个都开着」或「该开的没开」。

做完先**手动点一次运行**，再去时钟里看：应该只剩「明天该用的那一个」是开的。

> 表里 `""`（空字符串）表示当天不用闹钟 —— 两个如果都不命中，结果就是两个都关着。正好是对的。

> **为什么不给你一个现成的快捷指令文件导入？**
> iOS 15 起，快捷指令**必须由 Apple 服务器签名**才能导入；而签名要登录 iCloud
> （`shortcuts sign` 的报错原话就是这个），我这边做不到。详见 [DEVELOPMENT.md](DEVELOPMENT.md)。
> `tools/make_shortcut.py` 里保留了动作连线的写法，将来若有 Mac 可以一键生成可导入版本。

#### 第 3 步：建自动化

1. 「快捷指令」→ **自动化** → `+` → **特定时间** → 每天 `22:00` → 下一步
2. 选择第 2 步做的那条快捷指令
3. 关掉「运行前询问」；iOS 16 还要关掉「运行时通知」

**这次锁屏时应该也能跑** —— 它不打开任何 App。第二天去时钟里核对一下即可。

> ⚠️ 对照表是**预先算好发布**的。课表或提前量变了，要重新生成：
> ```
> python tools/gen_alarms.py 我的课表-2026-2027-1/timetable.json -o out/alarms.json --max-start 10:15
> ```
> `--max-start 10:15` 就是「只给 10:15 之前开始的课设闹钟」。想恢复全时段，去掉这个参数即可。


### 方案二：快捷指令打开 URL（解锁时用，时间精确）

响课注册了 `xiangke://apply`，被打开时会自动执行一次「应用课表」，
按课表当场算出闹钟 —— 时间最精确，但**只在解锁时可用**。

1. 「快捷指令」→ 新建 → 添加动作 **打开 URL** → 填 `xiangke://apply`
   （建议命名为「响课自动设闹钟」）
2. **自动化** → `+` → **特定时间** → 每天 `22:00` → 下一步
3. 选刚才那条快捷指令
4. 关掉「运行前询问」；iOS 16 还要关掉「运行时通知」

> ⚠️ **锁屏时这个自动化会失败**，提示「无法打开"响课"，因为 iPhone 已锁定」。
> 这是 iOS 的硬限制，改不掉 —— 锁屏时段靠方案一。

### 方案三：后台刷新（兜底，别指望）

App 向系统登记了后台任务，系统在合适时机唤醒它执行一次。
**实测不可靠**：三天一次都没被唤醒过。

如果要用：到「设置 → 通用 → 后台 App 刷新」确认「响课」是开着的，
并且**不要从后台把响课划掉**。

### ⚠️ 用了方案一之后，别再点主页的「立即应用」

「立即应用」会额外建一个 `课表|周X 课程名` 的闹钟，而方案一只管那 6 个固定闹钟 ——
两者会同时响。等 App 改成同一套模型后就没这个问题了。

### 锁屏探针

「设置 → 锁屏探针」可以看 App 每次被执行时的记录：当时是否锁屏、
能不能读写系统文件。排查问题时很有用。

> 顺带说明：本想用 **App Intent**（让动作直接出现在快捷指令里）来兼顾「锁屏 + 时间精确」，
> 但当前这套纯命令行的构建方式**生不出 App Intent 所需的元数据**，
> 动作不会出现在快捷指令里。原因与后续路径见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 常见问题

**Q：重启手机或 App 后课表会丢吗？**
不会，课表保存在磁盘上。主页「设置」→「存储自检」可以查看它存在哪、
是否可写、上次保存是否成功。

**Q：点了「立即应用」，但时钟 App 里没看到闹钟？**
1. 把系统「时钟」App 从后台划掉重开一次（它是懒加载的）
2. 回响课看日志区有没有报错
3. 如果**次日没有课**，响课会主动不设闹钟并清掉旧的课表闹钟 —— 这是正常行为

**Q：会误删我自己设的闹钟吗？**
不会。响课只处理标题以 `课表|` 开头的闹钟。

**Q：为什么不用 App Intent（让动作直接出现在快捷指令里）？**
`AppIntents` 框架是 Swift-first，本项目构建链是纯 clang 编译 Objective-C，
引入 Swift 混编的代价远大于收益。URL Scheme 同样能被定时自动化驱动。

**Q：导入课表时报「只支持 https」？**
iOS 默认禁止明文 http 请求。用 Gist 的 raw 地址（https）即可。

**Q：导入页的「粘贴」按钮是灰的？**
说明剪贴板里没有文字 —— 先去复制课表地址再回来。
如果确认复制过却还是灰的（或提示剪贴板为空），改用「从「文件」选 JSON」：
把 JSON 存到「文件」App 里直接选，这条路完全不经过剪贴板。

**Q：导入后主页提示「课表为空」？**
如果你只用 `overrides` 写课表（`courses` 留空），老版本会误报。当前版本已修正：
两种都为空才会提示。
