响课 · 开关闹钟

每天自动开关「时钟」里那 2 个早课闹钟。不打开任何 App，锁屏时也能跑。

为什么是「开关闹钟」而不是「设置闹钟」
iOS 锁屏时禁止「打开 App / 打开 URL」，所以唤起响课那条路在锁屏必定失败。 但快捷指令的「开关闹钟」动作不需要打开 App —— 锁屏也能执行。
于是把问题拆成两半：闹钟预先建好（一次），每天只开一个、关另一个。

第 0 步：时钟里建 2 个闹钟

「时钟」→ 闹钟 → 右上角 +，建两个。重复全部设为「不重复」。

标签时间对应最早课
课表 07:5007:5008:20 的课
课表 09:4509:4510:15 的课

标签照抄，后面在快捷指令里要按它选闹钟。
其余时段（10:30 / 14:00 / 15:55 / 18:30 开始）不设闹钟。

第 1 步：搭快捷指令

「快捷指令」→ 右上角 + → 按下面的顺序添加 9 个动作。

两个前提
① Apple 的中文用的是 「词典」不是「字典」 —— 搜「字典」是找不到的。
② 顺序是特意排的：先算日期 → 再取网络数据 → 再查表。这样第 4 步的输入会自动接第 3 步、第 5 步的输入会自动接第 4 步 —— 只有第 5 步的「键」要手动选一次变量。
#动作（搜这个）设置
1调整日期（搜 日期）日期 = 当前日期（默认，不用改）；操作 = 添加；1 天
2格式化日期（搜 日期）日期 = 上一步结果；格式选「自定义」，填 yyyy-MM-dd
3获取 URL 内容（搜 URL） 地址填：
https://gist.githubusercontent.com/yhgeo/a1319b6b00cf0cd73c19a4b7f0d47fb8/raw/alarms.json
4从输入获取词典（搜 词典）输入 = 上一步的结果（默认就是）
5获取词典值（搜 词典）输入 = 上一步的词典（默认就是）；
「键」= 魔法变量「第 2 步的输出」 ← 唯一要手选的地方，见下方
6开关闹钟（搜 闹钟）闹钟选「课表 07:50」，操作 = 关闭
7开关闹钟（搜 闹钟）闹钟选「课表 09:45」，操作 = 关闭
8如果（搜 如果） 条件：第 5 步结果 是 07:50
在里面放一个「开关闹钟」：闹钟选「课表 07:50」，操作 = 打开
9如果（搜 如果） 条件：第 5 步结果 是 09:45
在里面放一个「开关闹钟」：闹钟选「课表 09:45」，操作 = 打开

第 5 步的「键」怎么填（最容易卡在这里）

「获取词典值」长这样：

获取词典值
  从 [ 词典 ]       ← 输入，默认就是第 4 步的结果，不用动
  获取 [ 值 ]       ← 保持「值」
  键   [ ______ ]   ← 这里要填第 2 步的输出

「键」不能用键盘打字 —— 每天日期都不同，必须动态取。操作：

  1. 点一下「键」右边那个输入框，弹出键盘；
  2. 在键盘上方那一排按钮里找 「魔法变量」（图标像小方块/闪电，通常在靠右的位置）；
  3. 点开后选 「格式化后的日期」（第 2 步那个动作的输出）；
  4. 「键」里会变成一个蓝色小胶囊，显示「格式化后的日期」—— 这就对了。

同样的手法第 8、9 步也会用到：那两个「如果」默认就接第 5 步的输出， 一般不用改；如果显示的不是「词典值」，用同样方式改成第 5 步的输出。

两个「如果」是互相独立的，不要嵌套
先无条件关掉两个，再按匹配结果打开对应的那个。这样不会出现「两个都开着」或「该开的没开」。

表里 ""（空字符串）表示当天不用闹钟 —— 两个「如果」都不命中，结果就是两个都关着。正好是对的。

第 2 步：先手动试一次

在快捷指令里点一下运行，然后打开「时钟」看：

  • 只剩一个闹钟是开着的（明天该用的那个）
  • 如果明天不用闹钟 → 两个都关着

第 3 步：建自动化

  1. 「快捷指令」→ 自动化 → + → 特定时间 → 每天 22:00 → 下一步
  2. 动作选刚才那条快捷指令
  3. 关掉「运行前询问」；iOS 16 还会要求再关掉「运行时通知」

锁屏时应该也能跑 —— 它不打开任何 App。第二天去时钟里核对一下即可。

说明

  • 对照表是预先算好发布的（Gist 里的 alarms.json）。课表或提前量变了要重新生成。
  • 「开关闹钟」的闹钟是按引用指定的，所以第 6～9 步必须从列表里选，不能手打标签。
